# Megalodonte — desktop

Antes de criar ou alterar interfaces, execute `megalodonte skills sync --project .`
quando o CLI estiver disponível e então leia
`skills/megalodonte-native-ui/SKILL.md`. Siga as regras comuns de composição,
estado e tema e as regras específicas de desktop. Se a skill ainda não estiver
no catálogo do Codex, a cópia versionada continua obrigatória.

Para investigação, implementação e validação de mudanças, leia
`skills/criterioso/SKILL.md`.
